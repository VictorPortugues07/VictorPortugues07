### Sobre mim

Sou desenvolvedor Full-Stack no **Grupo Trier**, onde atuo na modernização de um sistema corporativo em plena
transição para se tornar uma instituição de pagamento. No dia a dia, isso significa migrar telas legadas para
**Angular + Spring Boot**, otimizar consultas pesadas no **PostgreSQL** e ajudar a construir APIs de pagamento
próprias com foco em segurança e integridade transacional.

Gosto de entender o problema antes de escrever a primeira linha de código — seja otimizando uma query que estava
travando um relatório, seja desenhando a autenticação de uma API. Fora do trabalho, sigo estudando
**Inteligência Artificial** e **Cibersegurança** aplicadas ao desenvolvimento de software, e também sou violinista:
dou aulas voluntárias e já toquei em apresentações beneficentes em hospitais.

### Como eu trabalho

- **Entender antes de codar:** investigo o comportamento real do sistema (dados, logs, queries) antes de propor uma solução.
- **Performance como parte do trabalho, não um extra:** otimização de SQL e de fluxos transacionais faz parte da rotina, não é uma etapa opcional.
- **Segurança desde o design:** autenticação e autorização (JWT/OAuth2) pensadas desde o início do fluxo, não corrigidas depois.
- **Documentar para o time, não só para mim:** APIs documentadas com Swagger/OpenAPI para facilitar a integração entre squads.
